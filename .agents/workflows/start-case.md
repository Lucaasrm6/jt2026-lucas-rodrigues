# /start-case

Objetivo: impedir implementação antes de o problema estar definido.

```text
1. Read persistent project rules.
2. Write the business decision in one sentence.
3. Inventory data, grain, joins and semantic uncertainty.
4. Predefine what "best" means before ranking.
5. List competing hypotheses.
6. State the cheapest evidence that could change confidence.
7. Rank analyses by decision value / time cost.
8. Define checkpoint output.
9. Only then implement.
```

STOP after the framing checkpoint and wait for review.
