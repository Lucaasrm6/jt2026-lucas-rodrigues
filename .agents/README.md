# Setup de agentes usado no hackathon

Este diretório registra a arquitetura operacional usada durante a análise. O objetivo não era executar sete respostas em paralelo, mas separar funções que entram em conflito quando ficam na mesma etapa: enquadrar, analisar, contestar, decidir, construir, auditar e comunicar.

## Componentes

- [`agents.md`](agents.md) — sete papéis e critérios de uso;
- [`skills/README.md`](skills/README.md) — inventário das 19 skills;
- [`workflows/start-case.md`](workflows/start-case.md) — framing antes de implementação;
- [`workflows/red-team.md`](workflows/red-team.md) — tentativa explícita de refutação;
- [`workflows/final-audit.md`](workflows/final-audit.md) — reprodução + consistência antes da entrega.

O histórico de como esse setup afetou o case está em [`../ai-log/02_setup_metodo.md`](../ai-log/02_setup_metodo.md).
